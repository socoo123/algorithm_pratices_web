# 基础面试题单 · 200 题（1-2 周计划）

> 面向 **一线大厂**算法面试的高频题单。按标签分组、双维度评分，目标 **1-2 周高强度过一遍**。

## 来源与定位
- **题源**：左神（左程云）算法体系 + LeetCode 高频面试题 + 一线大厂面经综合。
- **定位**：**题单**（不是逐题详尽题解）。每题只给「经典度 / 常考热度 / 核心考点」，刷题时直接去 LeetCode 写代码，卡住再看左神对应课程或 LC 官解。
- **题单侧重**：偏 Java、难度以 Easy-Medium 为主、Hard 较少、看重代码规范与边界处理、常考链表/树/DP/滑动窗口。

## 评分体系
- **经典度 ★**：该题在算法体系中的经典程度 / 是否「必会地基」。`★★★★★` = 必须烂熟于心。
- **常考热度 🔥**：面试真实出现频率（一线大厂）。`🔥🔥🔥🔥🔥` = 近乎必考。

> 两个维度独立：有的题经典度高（体系地基）但热度中等；有的题热度极高（面经常现）但不那么「体系核心」。两个维度都高的题 = **第一优先**。

## 使用方法
1. 按标签文件里的「推荐刷题顺序」从上往下刷（已按难度和依赖排好）。
2. 先刷该标签里 `★★★★★ + 🔥🔥🔥🔥` 以上的题（第一梯队），时间紧可只刷第一梯队。
3. 错题标记，Day 7 / Day 14 集中二刷。
4. 面经高频题在各标签末尾「面试高频提示」里点名。
