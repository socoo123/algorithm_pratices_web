# 动态规划（50 题）

> DP 是面试的**重头戏和分水岭**，一线大厂必考。按类型刷是关键（不要乱刷）：**线性 → 网格 → 子序列 → 背包 → 股票(状态机) → 区间 → 树形**。每类有固定模板，先掌握模板再套题。

## 刷题建议
- **DP 三步**：定义状态 → 找转移方程 → 确定遍历顺序 + 初始值。
- **按子表顺序刷**（已按难度/依赖排好）：线性 → 网格 → 子序列 → 背包 → 股票 → 区间 → 树形 → 杂项。
- **必会模板**：背包（0-1 / 完全）、股票（状态机）、LCS/编辑距离、区间 DP、树形 DP。
- 时间：3 天过完 50 题（量最大）。题号均为 [leetcode.cn](https://leetcode.cn) 链接。

## 面试高频提示
- **近乎必考**：爬楼梯(70)、最大子数组和(53)、打家劫舍(198)、零钱兑换(322)、不同路径(62)、LIS(300)、买卖股票(121/122)。
- **区分度题**：编辑距离(72)、LCS(1143)、背包(416/494)、打家劫舍III(337)——写得出是强项。
- 面试常追问**「能否空间优化（滚动数组）」**，背包/路径/股票类都要会压维。
- 股票系列建议用**状态机统一写法**（hold/cash 状态），面试官最认可。
- 戳气球(312) 是 Hard 高频，区间 DP 模板代表，强加分。
